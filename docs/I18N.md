# Languages

The source code is in **Portuguese**; English is generated from it. Available languages: `en` (default) and `pt`.

## How the user changes language

- **In Odysseus:** Settings → **Appearance** → *Language / Idioma (Kit)*. Saves the choice in the browser and in a `kitlang` cookie, and the tool pages (Finance, Gym, Study, Setup…) follow it.
- **In the Android app:** start screen (step 1) and then **App Settings → Language / Idioma**. The app also notifies Odysseus (cookie `kitlang`) so the pages stay in the same language.
- **By default** (new installation): English. In the app, it follows the phone’s language if it is Portuguese.
- Server: `"language": "pt"` in `~/.config/odysseus-kit/config.json` changes the default language of the pages.

## How it works

| Part | Mechanism |
|---|---|
| Hub, Canva pages and setup assistant | `tools/i18n.py` translates the HTML/JSON before sending it, using the `i18n/en.json` dictionary (`web`) |
| Odysseus buttons (Tools, Appearance) | `web/ody-extras.js` loads the same dictionary from `/finance/i18n.json` |
| Android app | `Tr.t("texto em português")` with `android/app/src/main/assets/i18n_en.json`; XML texts use `res/values` (English) and `res/values-pt` |

## Add or fix translations

1. Write the text in Portuguese in the code (as it already is).
2. Run `python3 -I scripts/build_i18n.py` (uses the assistant’s DeepL key). It only translates what’s missing.
3. Manually fix anything that isn’t good in `i18n/en.json` (your corrections won’t be overwritten).
4. For the Android app, rebuild (the script copies the dictionary to the `assets`).

## Known limitations

- AI‑generated text (summaries, plans, answers) is produced in the language of the request; it isn’t translated by the dictionary.
- Sentences built with variable values are only translated if there’s a pattern in the dictionary; some may remain in Portuguese.
- `android/www/error.html` (the “no connection” screen) and notification alerts with text coming from the server are not yet translated.
- Widgets follow the Android system language, not the app’s.
- The translation server (`tools/translate`) returns the user‑translated text without going through the dictionary, intentionally.
